Choose where Silo keeps its caches

Each cache can use a different folder or drive. These are generated indexes, previews, and browser session files; your original photos stay where they are. Choose a shared folder first, then change any individual destination you want. If the folder you chose before looked empty, that can be normal on a fresh install: Silo creates each named cache folder as that feature starts saving data.

Drive reminderExternal or removable locations are flagged below; connect them before opening Silo. Browser cache and web-session storage includes cookies and site data, so keep that destination connected for saved web sessions. If any cache drive is missing, Silo pauses indexing until you reconnect or locate that cache. Available space is checked for each destination.

Storage estimates are approximate per 10,000 files. Thumbnails and converted previews vary with image size and format. Existing cache files are kept when you move a destination later. Silo settings, browsing state, logs, crash reports, phone and Messages backups, and Fallout Shelter copies use their existing app-data or backup destinations; they are not moved by this cache setup.
